# 📐 도면 양식·척도 마스터 — 용지 · 윤곽 · 표제란 · 척도

**기초제도 Ⅱ. 제도의 규격과 통칙 — 1. 제도의 규격 · 2. 도면의 크기 및 척도** 단원용 학습·수업 보조 도구입니다.
설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인·휴대폰에서도 작동합니다.

## 왜 만들었나

"A0은 841×1189" 같은 숫자는 외워도 금방 잊습니다. 그런데 규칙은 하나입니다 — **반으로 접으면 다음 크기**.
이 도구는 A0을 **직접 접어 A4까지 내려가 보게** 하고, 척도를 바꾸면 **그림만 커지고 치수 숫자는 그대로**라는 것을
눈으로 보여 줍니다. 학생이 제일 많이 틀리는 지점이 바로 그 둘입니다.

## 구성

| 모드 | 내용 |
|------|------|
| 📖 **배우기** (4쪽) | ① 표준과 KS 부문(21개 카드 뒤집기) ② A0→A4 접기 애니메이션 ③ 양식 5요소 켜고 끄기 ④ 척도 비교 |
| **도전 ①** 용지 고르기 | 실제 크기 + 척도 → 제도 영역에 들어가는 **가장 작은 용지** 고르기 |
| **도전 ②** 척도 계산 | 도면에 그어지는 길이 / 실제 길이 / 축척·현척·배척 판별 |
| **도전 ③** 도면 양식 | 도면 그림에서 빨간 부분의 이름 맞히기 + 양식 규칙 |
| 🎯 **종합시험** | 전 유형을 섞어 10문항 출제 후 **결과 제출** |

> 배우기를 끝까지 넘기면 탭에 ✓ 가 남습니다(localStorage). 배우기는 정답을 다 보여주는 단계라 **맞힐 필요가 없습니다.**

## 다루는 내용 (KS 근거)

| 주제 | 핵심 |
|------|------|
| 표준 | 국제(ISO·IEC) → 국가(KS·JIS·DIN·ANSI…) → 단체 → 사내 |
| KS 부문 | A 기본 · **B 기계** · C 전기전자 · D 금속 … X 정보 (21개), 제도 통칙 = **KS A 0005** |
| 용지 크기 | A0 841×1189 (약 1m²) → A1 594×841 → A2 420×594 → A3 297×420 → A4 210×297, 비 **1 : √2**, 접기는 **A4** 기준 |
| 제도 영역 | A0 821×1159 / A1 574×811 / A2 400×564 / A3 277×390 / A4 180×277 |
| 양식 5요소 | 윤곽선(**왼쪽 20 / 나머지 10mm**, 0.7mm 실선) · 표제란(**오른쪽 아래**) · 중심 마크(4개) · 구역 표시(**I·O 제외**, 한 구역 50mm) · 재단 마크(10×5mm) |
| 척도 | **축척**(1:x) · **현척**(1:1) · **배척**(x:1), 표시 = **척도 A : B** (A 도면 크기 : B 실제 크기) |
| 치수와 척도 | 척도와 관계없이 **모두 실제 치수**로 기입, 비례 아니면 **NS** 또는 치수 밑줄 |

> 도전 ①·②의 정답은 위 제도 영역 표로 **독립 검산**해 200문항 자동 확인했습니다.

  `배우기 ④`에서 척도를 바꾸며 "그림은 작아져도 치수는 60 그대로"를 짚어 주세요.
